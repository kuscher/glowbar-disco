# Picking up

- 1.0 (code 1) is built and works: tested on a Googlebook (x86_64, Android 17), launched with `./dc launch` and by
  a click on the icon in the app list. Glowbar Disco opens in its own window; a second click brings the same window
  back; no Disco task is left behind. The icon renders as designed in the launcher.
