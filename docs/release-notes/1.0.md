First release of Glowbar Disco, the shortcut: an icon in your app list that opens Glowbar Disco, the Glowbar's party
mode on Googlebooks. Click it again and the same window comes back. No window of its own, no permissions, no internet
access, about 30 KB.

Install: download `GlowbarDisco.apk` below on your Googlebook and open it (the README has the steps).
